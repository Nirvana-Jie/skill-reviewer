# Meeting Note Helper

This skill helps users work with meeting notes.

## Workflow

1. Read the user's meeting transcript or notes.
2. Summarize the key points.
3. Pull out action items and owners.
4. Return a nicely formatted markdown document.

Always include an executive summary, key decisions, action items, and next steps. Be thorough.

## Output

Return markdown.

## Tips

- Try to be helpful.
- Use your best judgment on length.
- If the transcript is long, summarize harder.
